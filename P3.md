## How Chat Systems Usually Work

Authentication Flow:

1. User logs in with credentials → Server issues JWT token
2. Client sends JWT in every request Authorization: Bearer <jwt>
3. Server verifies JWT signature (no DB lookup needed)
4. JWT contains claims: user_id, username, issued_at, expires_at

User Identification in Requests:

1. JWT payload contains user_id (extracted from verified token)
2. No need to query DB on every request
